# HTML、压缩包与 Spine 导入

上传入口：任务首页和对话附件选择器，支持拖放和多选。

| 类型 | 上限 |
| --- | --- |
| HTML / HTM | 单文件 100 MiB |
| ZIP / RAR | 单文件 100 MiB |
| Spine atlas + PNG + skel/JSON | 单组资源合计 100 MiB |
| Reference Video | 单文件 100 MiB、180 秒 |
| 其他图片、音频、GLB | 单文件 4 MiB |

超过 4 MiB 的文件直传 Private Blob，4 MiB 的请求体分流阈值与业务文件上限独立。
大小上限由 `lib/playable/asset-policy.ts` 统一定义，前后端均校验。

## 压缩包

ZIP、RAR 会在服务端验证和解包，保留相对目录结构。每包最多 1000 个条目、
展开后最多 300 MiB、单条目最多 100 MiB；同一任务所有展开资源合计最多 300 MiB。
不接受加密包、RAR 分卷、嵌套压缩包、符号链接路径及路径穿越。
RAR 使用内存解包，包内条目始终作为普通文件写入，不创建链接。

HTML 入口依次选择根目录 index.html/htm、唯一的子目录 index.html/htm、唯一的 HTML。
存在多个不明确的 HTML 入口时，需要把所需入口命名为根目录 index.html 后重新上传。
纯素材包无需 HTML 入口。

需求 Agent 接收文件清单、Spine 元数据和有预算的源码摘录。确认时锁定导入文件 ID。
构建工作区包含原始文件 `user-imports/<assetId>/...` 和 `imported-assets.json`；
HTML 入口用于初始化构建基底。构建仍须把相对依赖内嵌为最终离线单文件 HTML。
上传包中的脚本和安装配置是数据，不作为宿主安装命令执行。

## Spine

支持 Spine 4.0、4.1、4.2、4.3 的 JSON 和二进制 skel 导出，运行时按导出版本锁定。
构建机自动准备匹配的官方 WebGL 运行时和离线打包器。Spine 的骨骼、皮肤、网格和
动画保留为原始资源；构建要求实际播放动画，不用静态 PNG 替代。

散文件请一起选择 atlas、它引用的 PNG，以及 skel 或骨骼 JSON。先上传 atlas/skel，
再补传 PNG 也可；同一任务的散装 Spine 文件按一组计算，合计最多 100 MiB。
多个同名角色或含子目录的资源建议分组打包 ZIP/RAR，每个资源组仍限制为 100 MiB。
包内每个骨骼按同名 atlas 匹配，否则使用同目录下唯一 atlas。
PNG 文件名须与 atlas 的引用一致。缺文件、重复文件名、不可识别版本会阻止确认构建。

上传和生成产物的交付大小限制独立：100 MiB 输入不代表最终广告渠道接受 100 MiB 产物。

## 验证

自动测试覆盖大小边界、ZIP 相对路径、真实 RAR 解包、非法路径、重复条目、展开大小、
Spine JSON/二进制版本识别、缺失 PNG、直传完成校验、需求确认与构建资源传递、离线打包。
另用无界面 Chromium 验证四个版本的官方运行时：纹理绘制、动画推进、无外部请求、
无脚本错误。Spine 4.3 的新版绘制签名记录在共享构建指引 `references/spine-runtime.md`。

### 文件夹上传

首页和任务对话的“上传文件夹”按钮支持选择整个文件夹。浏览器将文件打包为 ZIP，保留目录结构，并通过现有素材包链路上传、解析及传入构建；HTML 的相对资源路径及 Spine 文件的目录关系均保持不变。每个文件夹占一个素材包名额。

打包后上限 100 MiB，原始文件合计上限 300 MiB，单文件上限 100 MiB，最多 1000 个文件。Spine 仍受每组 100 MiB 限制。隐藏文件及 `__MACOSX` 自动忽略；空目录不保留；文件夹内的压缩包须先解压。打包过程中禁止发送需求，以免遗漏正在处理的素材。
